# LearnHub

A web application built with Django and MySQL for online learning.

## Features
- Browse available courses
- View course details and lessons
- Enroll in courses
- Track enrolled courses
- User registration and authentication

## Tech Stack
- Python
- Django
- MySQL
- Bootstrap 5
- Git/GitHub

## How to Run
1. Clone the repository
2. Install dependencies: `pip install django mysqlclient`
3. Create MySQL database called `learnhub`
4. Update database settings in `settings.py`
5. Run migrations: `python manage.py migrate`
6. Create superuser: `python manage.py createsuperuser`
7. Run server: `python manage.py runserver`
8. Visit `http://127.0.0.1:8000`
